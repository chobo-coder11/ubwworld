# 울큰월드 🐋

브라우저에서 즐기는 가벼운 3인칭 고래 마을 시제품입니다. WebGL과 Three.js로 제작했습니다.

## 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`을 여세요. 서버는 환경변수 `PORT`가 지정되면 해당 포트를 사용합니다. Railway 등 Node.js 호스팅에서 설치 후 `npm start`로 실행할 수 있습니다.

## 조작

- WASD 또는 방향키 이동, Shift 달리기, 스페이스 점프
- 화면을 드래그하여 시점 변경, 마우스 휠로 확대/축소
- 모바일에서는 화면의 방향 버튼과 드래그 사용
- 광장의 스크린을 클릭하거나 스크린 버튼을 눌러 YouTube 주소 입력

스크린의 영상은 별도의 플레이어 창에서 재생됩니다. 영상 제공자가 외부 재생을 허용해야 하며 브라우저에서 재생 버튼을 요구할 수 있습니다. 멀티플레이와 영상 동기화는 포함되어 있지 않습니다. 캐릭터와 배경은 첫 버전의 창작 로우폴리 모델입니다.
